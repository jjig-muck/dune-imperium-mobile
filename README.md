# 듄: 임페리움 — 모바일 팬 에디션

**플레이:** https://jjig-muck.github.io/dune-imperium-mobile/

모바일 브라우저에서 설치나 로그인 없이 플레이하는 한국어 전략 보드게임입니다.
기본 모드는 **나 + AI 2명**, AI 3명과 난이도 쉬움·보통·어려움도 선택할 수 있습니다.
익스의 부상과 불멸은 게임 시작 전에 독립적으로 켜거나 끌 수 있습니다.

## 현재 구현 범위

이 프로젝트는 **원작 핵심 규칙을 기반으로 만든 선별 카드 팬 에디션**입니다.
상용 디지털판이나 원작 전체 카드·음모의 완전한 재현판이 아닙니다.
전체 카드풀, 모든 타이밍 예외, 하갈 가문 자동인형 규칙, 원작과의 완전한 규칙 대조는 아직 완료하지 않았습니다.
원작 규칙을 그대로 쓰는 대회나 정확한 실물판 연습용으로는 적합하지 않습니다.

| 영역      | 구현                                                                                       |
| --------- | ------------------------------------------------------------------------------------------ |
| 게임 진행 | 요원 파견 → 공개·구매 → 전투 음모 → 보상·메이커·회수 → 다음 라운드 → 종료                  |
| 솔로      | 일반 플레이어와 같은 자원·덱·배치 제한을 따르는 AI 2–3명                                   |
| 난이도    | 추가 자원 없이 의사결정 평가와 선택 변동성 변경                                            |
| 지도자    | 기본판 8명 + 익스 6명, 원본 명단과 지속·시작·인장 능력 구현                                |
| 카드      | 선별 제국 카드, 선별 틀레이락스 카드, 예비 카드, 기본 시작 덱                              |
| 음모      | 모바일 에디션용 선별·조정된 10종. 실물판 음모 전체와 동일하지 않음                         |
| 영향력    | 우호·동맹·동맹 쟁탈·트랙 보너스                                                            |
| 전투      | 병력·검·전투 음모·동률·3/4인 보상·지배지                                                   |
| 익스      | 수송 전진·귀환·누적 보상, 협상가, 기술 18종, 드레드노트·한 라운드 지배                     |
| 불멸      | 실험 시작 카드, 분기 연구 경로, 유전자 단계, 표본, 접합, 틀레이락스 트랙·시장, 가문 원자탄 |
| 로컬 다인 | 한 기기 2–4인, 차례 전환 시 손패 가림. 2인은 하갈 없는 직접 대전 변형                      |
| 저장      | 행동마다 브라우저 자동 저장, JSON 내보내기·가져오기, 이전 결정 되돌리기                    |
| 모바일    | 실물 구역 배치 / 모바일 확대 보기, 큰 비용·보상, 별도 전투 탭, 390px 화면 검수                                  |
| 오프라인  | 첫 접속 후 앱 파일 캐시, 웹 앱 설치용 manifest·아이콘                                      |

일부 전투 보상 선택지와 효과 처리 순서는 고정되어 있으며 원작의 모든 자유로운 효과 순서를 제공하지 않습니다.
공개 도중 뽑은 추가 카드는 이번 공개 효과를 자동 반복하지 않고 턴 종료 시 버립니다.
예비 카드 공급량은 무제한입니다.

## 지도자

기본판: 폴 아트레이데스, 레토 아트레이데스 공작, 블라디미르 하코넨 남작,
글로수 라반, 일반 리체스 백작, 헬레나 리체스, 멤논 소르발드 백작,
아리아나 소르발드 백작부인.

익스: 아르망 에카즈 대공, 일레사 에카즈, 롬버 버니우스 왕자,
테시아 버니우스, 유나 모리타니, 훈드로 모리타니 자작.
불멸에는 새 지도자가 없습니다. 익스를 끄면 확장 지도자는 선택 목록에서 제외됩니다.

## 플레이 방법

1. 상대 AI 수, 난이도, 확장, 지도자를 선택합니다.
2. 「손패」에서 카드를 고르고 「장소 보기」를 누르면 갈 수 있는 장소가 금빛으로 표시됩니다.
3. 장소를 선택하고 비용을 확인한 후 파견을 확정합니다.
4. 전투 장소에서는 이번 턴 모집 유닛과 기존 주둔지 유닛 최대 2개를 배치할 수 있습니다.
5. 요원을 더 쓰지 않으려면 손패를 공개하고 시장에서 카드를 구매합니다.
6. 모든 플레이어가 공개를 마치면 전투 탭으로 전환됩니다. 전투 음모를 사용하거나 통과합니다.
7. 목표 승점에 도달한 라운드가 끝나거나 10라운드 후 최종 승자를 정합니다.

보드 위 「실물 배치」는 왼쪽 세력, 위쪽 의회·CHOAM, 가운데 아라키스, 아래 전장이라는 실물판의 상대적 구역 배치를 따릅니다. 좁은 화면에서는 보드 자체를 좌우로 이동합니다. 「모바일 확대」는 같은 장소를 구역별로 크게 표시합니다.

상단 분쟁 요약이나 전투 탭에서 순위별 보상과 공용 전장을 확인할 수 있습니다. 하나의 전장 안에 모든 플레이어의 투입 병력·함선·전투력을 색상별로 표시하며, 주둔지는 전장 아래에 따로 표시합니다. 전투력 계산은 펼쳐서 확인합니다. 장소의 비용·보상은 작은 아이콘·숫자·이름을 한 줄로 표시하며, 장소를 누르면 상세 조건을 확인할 수 있습니다.

## 실행과 검증

Node.js 22 이상이면 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

`http://localhost:4173`을 엽니다. 같은 네트워크의 기기에서는 개발 PC의 IP와 포트로 접근할 수 있습니다.
이 개발 서버는 로컬 검수용이며 인터넷 공개용 서버가 아닙니다.

```sh
npm run check
npm test
```

테스트는 잘못된 파견 거부, 비용·점유, 접합, 병력 보존, 연구, 수송, 동률,
공개·구매·승점, 원자탄, 저장 복원을 검증합니다.
모든 14명 지도자 × 3개 난이도 = **42게임을 종료까지 자동 시뮬레이션**하며,
2/3 AI와 확장 조합을 바꾸어 상태 불변식을 확인합니다.
자동 대전은 규칙의 완전한 원작 일치나 AI의 숙련자 수준을 증명하지 않습니다.

`http://localhost:4173/__mobile`은 너비 390px iframe을 제공하는 개발용 반응형 검수 화면입니다.
실제 iPhone Safari·Android Chrome 실기기 검증을 대신하지 않습니다.

## GitHub Pages

`.github/workflows/pages.yml`에서 검증 후 정적 파일만 스테이징하여 Pages에 배포합니다.
서버·데이터베이스·API 키·실행 중 외부 AI 호출이 필요하지 않습니다.
코드나 애셋을 바꾸면 `sw.js`의 캐시 버전을 올리세요.
기존 클라이언트는 온라인 접속 시 새 파일을 우선 가져옵니다.

### 파일 구성

- `src/engine.js`: DOM과 분리된 상태 전이·규칙·검증
- `src/ai.js`: 공개 정보와 자신의 손패를 사용하는 AI 의사결정
- `src/data.js`: 지도자·카드·장소·기술·전투·연구 경로
- `src/app.js`: 한국어 UI·자동 저장·대화상자·턴 스케줄러
- `styles.css`: 반응형 화면·접근성·모션 감소 설정
- `assets/`: 프로젝트용 원본 SVG와 설치 아이콘
- `tests/engine.test.mjs`: 규칙 및 완주 시뮬레이션

## 저장과 개인정보

진행은 현재 브라우저의 `localStorage`에 저장됩니다. 기기 간 동기화는 없습니다.
브라우저 데이터 삭제, 시크릿 모드 종료, 기기 변경 전에 JSON 파일로 백업하세요.
새 게임이나 저장 파일 가져오기는 기존 자동 저장을 교체하기 전에 확인합니다.
플레이 로그를 외부 서버로 보내지 않습니다.
Google Fonts는 온라인에서 요청하며 이용할 수 없으면 시스템 글꼴로 표시합니다.

## 출처와 권리

이 프로젝트는 Dire Wolf Digital, Gale Force Nine, Legendary와 제휴하지 않은 팬 프로젝트입니다.
Dune 및 Dune: Imperium의 상표·세계관·캐릭터 등 권리는 각 권리자에게 있습니다.
화면은 텍스트·가문 문양·기능 아이콘 중심으로 구성합니다. 배경 일러스트와 지도자 초상은 사용하지 않습니다.
공식 카드 이미지, 영화 스틸, 게임판 스캔은 포함하지 않았습니다.
이 저장소의 MIT 라이선스는 이 프로젝트가 새로 작성한 코드·SVG에 적용되며,
원작의 상표·세계관 등에 대한 사용권을 부여하지 않습니다.
